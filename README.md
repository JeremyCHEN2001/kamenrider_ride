# 疾风 · SHIN RIDER

参考《新假面骑士》造型的非官方同人 3D 摩托骑行游戏。角色配色、复眼、触角、红围巾和白红旋风号参考本目录的 `ref.jpg`；场景为电影氛围启发的原创程序化山路、采石场、隧道，并非电影场景的逐镜还原。

## 运行

直接用 Chrome / Edge / Safari 打开 `index.html` 即可游玩，无需安装依赖、构建或联网。浏览器须支持 WebGL。

也可以在本目录运行：

```sh
python3 -m http.server 8080
```

然后打开 http://localhost:8080 。手机与电脑在同一局域网时，可通过电脑 IP 和相同端口访问。

## 操作与目标

- W / ↑：油门；S / ↓：刹车；松开后缓慢回到约 110 km/h 巡航速度。
- A D / ← →：转向；空格：跳跃；E：按住吸风；Shift：蓄压后喷焰加速。
- 默认追逐视角；C 切换追逐、侧面、骑士、电影四种预设镜头，滚轮缩放。鼠标左键拖动不再改变视角。每次开始或重开均恢复追逐视角。
- P：暂停；M：引擎与收集音效；R：重开。
- 触屏：单指按住正常前进，左右滑动转向；双指按住加速（等同 Shift）。跳跃、吸风、刹车、加速也可用屏幕按钮；页面右上角可查看说明或切换全屏。
- 每局开始的障碍车道会重新随机，首个能量固定在中线，三条车道均有可见标线。

完成 3 公里突破任务，收集绿色能量，每个 25 分；每公里切换下一场景。黑黄路障造成装甲损伤，五次碰撞后失败。跳跃可以避障。完成奖励 500 分，里程每 10 米奖励 1 分，最高分保存在浏览器本地。音效默认关闭，点击「声音」开启。

## 风之力与高速骑行

- 巡航 110 km/h，常规极速 220 km/h，喷焰极速 320 km/h；结束喷焰后平滑减速。
- 车速达到 40 km/h 后自动少量蓄风，按住 **E** 主动吸风，每秒恢复 30% 风能；吸风时最高速度限制为 170 km/h。
- 至少 20% 风能可启动喷焰：按住 **Shift** 蓄压 0.55 秒，六根排气管喷焰，每秒消耗 28% 风能。松开立即结束推力；耗尽后须松开再蓄能，避免自动重复点火。
- 骑行气流随速度增强，主动吸风时气流向车头汇聚；喷焰时镜头视野加宽。
- 红围巾加长到 3.5 个模型单位，颈部固定，波浪向末端传播；高速时拉直并加快抖动，低速时自然下垂。
- 手机单指按住前进、左右滑动转向，双指按住加速；「吸风」「刹车」「跳跃」「加速」按钮与键盘机制一致。

运行 `node tests/smoke.cjs` 检查游戏逻辑（使用真实 Three.js 场景对象与模拟渲染器，覆盖随机车道布局；画面需另外在浏览器验证）。

模型更新：头盔口部改为贴合下颌的薄面甲，收回侧面轮廓；复眼加入贴面细分，胸甲改为棱面分片；摩托改用分段导流罩、斜风挡和收窄的双灯鼻部。
